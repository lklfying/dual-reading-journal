⚙ 设置与数据

所有数据保存在本浏览器 localStorage。两人同步：一方导出 JSON 发给另一方导入。

导出数据备份

导出全部数据（读书输出、评论、书架）为 JSON 文件。

导入数据备份

导入同伴发来的 JSON，合并双方数据。

清空数据

删除本浏览器中的全部数据（不可恢复）。

两人同步使用说明

  1. 「我」写作并提交输出后，进入「设置」→「导出 JSON」。
  2. 将 JSON 文件发送给「同伴」（微信 / QQ / 邮件均可）。
  3. 「同伴」在自己的浏览器打开本页面 →「设置」→「导入数据备份」选择该文件，即可看到我的输出并回复。
  4. 反向同理：同伴导出后发回给我导入，即可互相看到对方的读书输出、回复与书架。
  5. 书架导入在各自浏览器独立保存，导入数据时会一并合并。
